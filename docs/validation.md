# 工作台优化与验证

日期：2026-11-09；环境：macOS、Node.js 24.14.1、Yarn 1.22.22。

## 改动范围

新增 Grid Studio 工作台、布局配置校验、本地保存与导入导出；保留组件库公共 API、作者与许可。常用开发和构建命令不再依赖 Make。

修复 WidthProvider 在 measureBeforeMount 模式下的观察目标切换：占位节点替换为真实网格时解除旧订阅、观察新节点，忽略移除或隐藏节点的零宽度通知，卸载时清理。之前桌面容器宽度正常但卡片被计算为 0px，新回归用例与真实浏览器验证均覆盖此问题。

同时清理已有 ESLint 未使用参数/可用 const 的问题；不改变排序与碰撞算法。工作台包装组件同步首屏实际断点，避免手机布局正确但列数标签仍显示 lg。
